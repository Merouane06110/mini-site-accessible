# Mini-Site Accessible

Mini-site web réalisé dans le cadre de la formation **Développeur Web & Web Mobile**.

Ce site respecte les bonnes pratiques :
- HTML5 / CSS3
- Accessibilité (WCAG + ARIA)
- SEO
- Navigation claire
- Formulaire accessible
- Tableaux structurés
- Médias, styles externes, polices
- Préparation à l'ECF

## 🚀 Fonctionnalités

### ✔ Accessibilité
- Navigation au clavier
- Texte alternatif pour les images
- Contraste lisible
- ARIA sur les éléments interactifs

### ✔ SEO
- Balises title et meta description uniques
- Structure H1 → H2 → H3 logique
- URLs propres

### ✔ Formulaire complet
- Champs obligatoires
- Labels associés
- Contrôle d'email HTML5

### ✔ Tableaux accessibles
- Caption
- Balises <th> avec scope="col"

### ✔ Médias
- Images avec alt
- Vidéo avec fallback et contrôles
